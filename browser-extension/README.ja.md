# ChatGPT Completion Sound

ChatGPTの回答生成が終了したときに、ローカル通知音を再生する
Chrome / Brave向け Manifest V3 拡張です。

## 機能

- Chime / Bell / Double / Soft / 電子レンジ風チン / ブライトベル /
  ゲームクリア風 の7種類
- 拡張専用の音量調整
- ON/OFF
- テスト再生
- 音の種類・音量変更時の自動プレビュー
- 英語／日本語UI
- 解析、テレメトリ、広告、アカウント、リモートコードなし

## 完了判定

ユーザーの送信操作を確認した後だけ監視を開始し、
ChatGPTの正式な生成中コントロール
`[data-testid="stop-button"]` の出現→消失を完了条件にします。

別の既存チャットへ移動した場合は、それまで追跡していた回答状態を破棄します。

## 拡張機能を更新した後

拡張機能の更新前からChatGPTタブを開いていた場合は、そのタブを一度
再読み込みしてください。再読み込みするまで旧content scriptが残る場合があります。

## プライバシー

`chatgpt.com` 上だけで動作し、設定は `chrome.storage.local` にローカル保存します。
会話内容を拡張機能が外部送信することはありません。

OpenAI非公式の独立拡張です。
