# 権限の使用理由

## Chrome / Brave

### `storage`

以下の拡張設定だけをローカル保存します。

- ON/OFF
- 選択した通知音
- 音量

会話パスや完了判定状態は一時的にメモリ上へ保持するだけで、
拡張ストレージへ永続保存しません。

クラウド同期ストレージは使用しません。

### `offscreen`

Manifest V3のバックグラウンド環境から、同梱通知音を再生するために使用します。

### ホスト権限 `https://chatgpt.com/*`

ChatGPTのUI状態をローカル監視し、生成終了を判定するcontent scriptに必要です。

全Webサイトへの権限は要求せず、ChatGPTのみに限定しています。

## VS Code

VS Code拡張にはブラウザ拡張のような権限確認UIはありません。
ローカルVS Codeプロセスの権限で動作します。

Codexデータへのアクセス先は実装上、
`~/.codex/sessions`（または `CODEX_HOME` 配下の同等パス）の
ローカルrollout JSONLと、拡張自身のストレージ／同梱音声素材に限定しています。
rolloutファイルはローカルで読み取り、変更・外部送信しません。
