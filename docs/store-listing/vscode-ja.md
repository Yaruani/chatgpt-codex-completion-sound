# VS Code Marketplace 掲載文 — 日本語

## 表示名

Codex Completion Sound

## 短い説明

VS Code内のCodexタスク完了時に選択可能なローカル通知音を再生します。非公式拡張です。

## Marketplace説明

Codexの処理中に画面を見続ける必要をなくすための完了通知拡張です。

Codex Completion Sound は、ローカルのCodexセッションイベントを読み取り専用で監視し、
VS Code由来のCodexタスクが完了すると短い通知音を鳴らします。

機能:

- 4種類の同梱通知音
- 0～100%、5%刻みの音量設定
- Command Paletteから音選択・テスト再生
- ON/OFF
- 英語／日本語UI
- 解析、テレメトリ、広告、アカウント、独自ネットワーク通信なし
- Codexセッションはローカル・読み取り専用

本リリースの通知音再生はWindows対応です。

OpenAI非公式の独立拡張であり、OpenAIによる承認・提携を意味しません。
