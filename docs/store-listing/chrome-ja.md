# Chrome Web Store 掲載文 — 日本語

## 名前

ChatGPT Completion Sound

## 短い説明

ChatGPTの生成終了時にローカル通知音を再生します。解析・データ送信は行いません。

## 詳細説明

ChatGPT Completion Sound は、ChatGPTの生成が終了したときに音で知らせる拡張機能です。

機能:

- Chime / Bell / Double / Soft / 電子レンジ風チン / ブライトベル /
  ゲームクリア風 の7種類
- 拡張専用の音量調整
- ON/OFF
- ワンクリックのテスト再生
- 音の種類・音量変更時の自動プレビュー
- 複数の生成中ChatGPT会話を会話ごとに独立追跡
- 回答生成中に別のChatGPT会話へ移動しても元の会話を追跡
- ChatGPTページが開いた状態であれば、バックグラウンドタブや
  ブラウザ最小化中も通知可能
- 複数回答が近い時刻に完了しても通知音を順番に再生
- 英語／日本語UI
- ChromeおよびBrave等のChromium系ブラウザで利用可能

プライバシー:

- 解析・テレメトリなし
- 広告なし
- アカウント／ログインなし
- リモートコードなし
- ユーザーデータを販売・共有しない
- ChatGPTの会話内容を拡張が外部送信しない
- 設定は端末内にローカル保存
- 会話パスや追跡状態は一時的に拡張機能のメモリ上だけに保持

`chatgpt.com` へのアクセス権限は、生成中／完了のUI状態をローカルで判定し、
完了時に同梱通知音を再生するためだけに使用します。

OpenAI非公式の独立拡張であり、OpenAIによる承認・提携を意味しません。
