# Chrome Web Store 掲載文 — 日本語

## 名前

ChatGPT Completion Sound

## 短い説明

ChatGPTの生成終了時にローカル通知音を再生します。解析・データ送信は行いません。

## 詳細説明

ChatGPT Completion Sound は、ChatGPTの生成が終了して入力可能な状態へ戻ったときに、
音で知らせる拡張機能です。

長い処理を依頼したあと、ChatGPT画面を見続けずに別タブや別アプリで作業する用途を
想定しています。

機能:

- Chime / Bell / Double / Soft の4種類の通知音
- 拡張専用の音量調整
- ON/OFF
- ワンクリックのテスト再生
- 英語／日本語UI
- ChromeおよびBrave等のChromium系ブラウザで利用可能

プライバシー:

- 解析・テレメトリなし
- 広告なし
- アカウント／ログインなし
- リモートコードなし
- ユーザーデータを販売・共有しない
- ChatGPTの会話内容を拡張が外部送信しない
- 設定は端末内にローカル保存

`chatgpt.com` へのアクセス権限は、生成中／入力待ちのUI状態をローカルで判定し、
完了時に同梱通知音を再生するためだけに使用します。

OpenAI非公式の独立拡張であり、OpenAIによる承認・提携を意味しません。
