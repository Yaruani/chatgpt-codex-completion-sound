# VS Code Marketplace listing — English

## Display name

Codex Completion Sound

## Short description

Plays a selectable local notification sound when a VS Code Codex task completes. Unofficial.

## Marketplace summary

Stop watching the Codex panel while a task runs.

Codex Completion Sound monitors local Codex session events in read-only mode
and plays a short sound when a VS Code-originated Codex task completes.

Features:

- Four bundled sounds.
- 0–100% volume control in 5% steps.
- Sound selection and test playback from the Command Palette.
- On/off toggle.
- English/Japanese UI.
- No analytics, telemetry, ads, accounts, or network requests.
- Local, read-only Codex session monitoring.

Windows is supported for notification playback in this release.

Unofficial extension. Not affiliated with or endorsed by OpenAI.
