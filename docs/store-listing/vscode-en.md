# VS Code Marketplace listing — English

## Display name

Codex Completion Sound

## Short description

Plays selectable local notification sounds when VS Code Codex main or optional subagent turns complete. Unofficial.

## Marketplace summary

Stop watching the Codex panel while a task runs.

Codex Completion Sound monitors Codex's local rollout JSONL session files and
plays a notification as soon as a turn completes.

Features:

- Seven bundled sounds: Chime, Bell, Double, Soft, Microwave Ding, Bright Bell,
  and Game Clear.
- 0–100% volume control in 5% steps.
- Native VS Code Extension Settings UI.
- Separate main and subagent sound selection.
- Subagent completion notifications are optional and disabled by default.
- Shared application-wide settings across VS Code windows.
- Automatic preview when sound or volume settings change.
- Test playback and settings commands from the Command Palette.
- Real-time local rollout monitoring with inherited/stale/replayed history
  suppression.
- Multiple simultaneous Codex tasks can each notify independently.
- Near-simultaneous sounds are queued rather than overlapped.
- English/Japanese UI.
- No analytics, telemetry, ads, accounts, or network requests.
- A local single-instance lock prevents duplicate monitoring across multiple
  VS Code windows.

Windows is supported for notification playback in this release.

Unofficial extension. Not affiliated with or endorsed by OpenAI.
