# VS Code Marketplace listing — English

## Display name

Codex Completion Sound

## Short description

Plays a selectable local notification sound when a VS Code Codex turn completes. Unofficial.

## Marketplace summary

Stop watching the Codex panel while a task runs.

Codex Completion Sound monitors Codex's local `~/.codex/logs_2.sqlite`
database in read-only mode and reacts to App Server `turn/completed` lifecycle
events.

Features:

- Seven bundled sounds: Chime, Bell, Double, Soft, Microwave Ding, Bright Bell,
  and Game Clear.
- 0–100% volume control in 5% steps.
- Native VS Code Extension Settings UI for enable/disable, sound, and volume.
- Automatic preview when the selected sound or volume changes.
- Test playback and settings commands from the Command Palette.
- English/Japanese UI.
- No analytics, telemetry, ads, accounts, or network requests.
- Local, read-only Codex App Server log monitoring.
- A local single-instance lock prevents duplicate completion sounds from
  multiple VS Code windows.

Windows is supported for notification playback in this release.

Unofficial extension. Not affiliated with or endorsed by OpenAI.
