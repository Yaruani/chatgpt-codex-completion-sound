# Support

## Before opening an issue

1. Update to the latest release.
2. Restart/reload the browser or VS Code.
3. Run the built-in test sound.
4. For VS Code, run `Codex Completion Sound: Diagnostics`.
5. Do not attach Codex session files or private conversation content.

## Useful issue details

- Extension version
- Browser / VS Code version
- Operating system
- Whether the test sound works
- Exact steps to reproduce
- Diagnostic output with private paths redacted if desired
